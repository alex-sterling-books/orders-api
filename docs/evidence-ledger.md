## 2. Predictions

For each hypothesis, write what you would see if it were true. The useful rows
are the ones where the hypotheses predict different things.

| Question | If A is true | If B is true | Observation IDs | Fits |

## 3. Verdicts

| Hypothesis | Verdict | Deciding evidence | What would change this verdict |
| --- | --- | --- | --- |
| A | Verified / Rejected / Contributing / Open | | |
| B | Verified / Rejected / Contributing / Open | | |

Verdict meanings:
- Verified: survived a test that could have proved it wrong.
- Rejected: a test it should have passed, it failed.
- Contributing: real and adds to impact, but does not explain the incident on its own.
- Open: not yet tested.
